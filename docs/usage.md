# 使用指南

[返回首页](../README.md) · [配置参考](configuration.md)

## 给角色配置工具

在左侧菜单打开「工具暴露」，选择角色。列表中的预设 ID 用于保存设置，切换 DSH 界面语言后仍使用同一 ID。长说明压缩为一行，悬停可查看全文。

1. 设置默认规则。选「默认开放」可先开放所有受管工具，再关掉个别工具或组。选「白名单」可从全部隐藏开始，按需放行。
2. 点击工具组名称可展开详情。组开关作用于该组全部工具，逐个调整时组状态会显示「部分可见」。先设整组开关，再设单个例外，便于核对最终结果。
3. 展开「最终可见工具」，检查当前草稿的可见与隐藏清单。
4. 点击「保存」。看到「已保存，新建会话生效」后，用同一角色新建会话验证。

「恢复全局默认」会清除该角色的覆盖项，让它重新继承「高级设置 → 全局」里对未单独配置角色的默认规则。点击「保存」后，新规则用于新建会话。

## 查找工具和 MCP

搜索可匹配工具名、说明、插件名或 MCP 服务器名，并可叠加「仅可见」或「仅隐藏」。搜索结果缩小的是列表范围，组开关始终作用于整组。清除筛选后，分组恢复筛选前的展开状态。

| 工具组 | 页面显示 |
| --- | --- |
| 官方工具 | 展开后可查看每项工具由哪个官方插件注册。 |
| 全局 MCP | 每个通过 DSH 全局 MCP 注册且已有工具的服务器独立成组，以连接中的服务器名称显示。每个组都可以单独开关。 |
| 第三方插件 | 按注册工具的插件分组。页面优先显示插件提供的名称和图标，并显示包名。 |
| 自定义组 | 在「高级设置 → 管理工具组」里用工具名或通配符建立。匹配顺序见[配置参考](configuration.md#分组规则)。 |
| 来源未知 | 归集缺少注册插件身份、且未被自定义组匹配的工具。 |

要为某个角色隐藏一个全局 MCP 服务器，找到对应服务器组，关闭组开关并保存。要保留该组的一项工具，展开该组再打开那一项。其他 MCP 服务器按各自的开关和角色默认规则计算。

## 草稿和扫描

- 点击「返回会话」会保留本次页面加载期间的草稿、所选角色、搜索和展开状态。重新打开「工具暴露」可继续编辑。
- 安装插件、连接新 MCP 服务器或改动预设之后，可点击「重新扫描」读取最新注册清单。页面会在覆盖未保存草稿前提示确认。
- 「放弃修改」会回到最近一次已加载或已保存的配置。发生保存冲突时，页面会保留当前草稿。先记下要保留的改动，再重新扫描载入最新配置并合并。
- 保存和扫描的结果通过页面底部浮层提示。成功提示会自行消失，错误提示可以手动关闭。

## 常见问题

### 侧栏找不到「工具暴露」

在「插件 → 已安装」里确认插件已启用，重启 DSH，再从侧栏或「更多」打开。如果页面提示矩阵数据加载失败，确认当前配置使用官方 `dsh-base`，然后重试。

### 已连接的 MCP 没有独立工具组

确认连接在 DSH 中全局启用，并等待服务器成功注册工具，然后点击「重新扫描」。独立 MCP 组来自全局注册，预设内的工具按其注册来源归组。

### 刚保存，当前会话仍能看到原来的工具

每个会话使用建立时应用的工具策略。用同一角色新建会话即可使用已保存的规则。若要解除本插件对当前所有已加载会话及子代理的限制，打开「高级设置 → 解除所有当前会话的工具限制」，按提示确认。以后新建的会话仍使用已保存的规则。

### 页面处于只读状态

当前 DSH 环境没有提供配置编辑服务。可在该配置档案的 `cordis.patch.yml` 中修改 `tool-exposure` 行，再重新加载对应配置。字段和示例见[配置参考](configuration.md)。

## 升级与卸载

升级前可备份当前配置档案中 `tool-exposure` 行的 `config`。在「插件 → 已安装」打开「工具暴露」并卸载旧版，再按[首页的安装步骤](../README.md#安装)安装新版。安装后重启 DSH，再将需要沿用的规则合并到新版配置并核对。

卸载后重启 DSH。若要立即解除已加载会话的限制，请在禁用或卸载前先使用高级设置里的解除按钮。已有会话上的限制也会在会话销毁时释放。
